Solution

6つの機能で、
当日の全業務を整える。

海況判断・体調リスク・多言語通知・チェックイン・安全同意・ダッシュボード。OPePeが当日の全業務を1つのツールで整える。

Benefit

出発前に、ガイドとしての準備ができる。参加者の顔を見る余裕が生まれる。安全同意の記録が法的根拠として残る。スタッフへの引き継ぎができる業務になる。OPePeは「効率化ツール」ではなく、ツアーの質を上げるインフラだ。

🌊
NEW

海況自動取得 + 判断補助

活動拠点を設定するだけで波高・風速・降水確率をリアルタイム取得。🔴中止推奨・🟡要検討・🟢実施可能を自動判定。中止決定時の海況データを自動蓄積。

🩺
NEW

参加者体調リスク可視化

飲酒・睡眠・持病を事前セルフチェック。回答を🔴🟡🟢でダッシュボードに表示。声かけが必要な参加者を出発前に把握。フラットな設計で正直な申告を促す。

📝
安全記録

安全同意デジタル記録

参加者がマイページで安全事項を確認・同意。「誰が・いつ・何に同意したか」をCSVで30秒以内に出力。紙の同意書が濡れて消える時代は終わり。

📢
通知

10言語一斉通知

天候判断をしたら1タップで全参加者へ多言語通知。日本語・英語・中国語・韓国語など10言語に自動翻訳。インバウンド客への個別翻訳作業がゼロになる。

📲
チェックイン

QRセルフチェックイン

集合場所にQRを掲示するだけ。参加者が自分でスキャンしてチェックイン。同伴者も代表者のQRで一括チェックイン。名前を呼ぶ作業は終わり。

📊
ダッシュボード

全員の状況をリアルタイム把握

チェックイン・遅刻・場所不明・体調・安全同意の状況が一画面で確認できる。参加者マイページは10言語対応。インバウンド客が自分で情報確認できる。

How it works

3ステップで、
当日が変わる。

01

ツアーと参加者を登録する

ダッシュボードから実施回を作成し、参加者を追加。じゃらん・アソビュー・電話など、どの予約経路でも対応。活動拠点の位置を設定すれば、海況が自動で表示される。

📅 実施回を作成 → 参加者を追加 → 海況が自動表示
02

ワンタイムURLを参加者に送る

集合場所・持ち物・体調確認・安全同意が入ったマイページのURLをLINEで送信。参加者は前日までに体調を申告・同意を完了。当日朝に事業者は体調リスクを把握できる。

📨 URL送信 → 体調申告 + 安全同意 → 完了
03

当日はダッシュボードを見るだけ

海況スコアを確認して通知を送る。QRでチェックイン。体調リスクのある参加者に声をかける。電話対応ゼロで、準備が整った状態で出発できる。

🌊 海況確認 → 📲 QRチェックイン → 🔴 体調確認 → 出発
